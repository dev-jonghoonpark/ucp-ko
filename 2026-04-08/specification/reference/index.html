    스키마 레퍼런스¶

    이 페이지에서는 UCP에서 사용하는 모든 기능 데이터 모델과 타입의 레퍼런스를 제공합니다.

    기능 스키마¶

    Cart¶

    이름 타입 필수 설명
    ucp any 예 장바구니 응답용 UCP 메타데이터. 체크아웃 전에는 결제 핸들러가 필요 없습니다.
    id string 예 고유 장바구니 식별자.
    line_items Array[Line Item] 예 장바구니 라인 아이템. 체크아웃과 구조가 같습니다. 업데이트 시 전체를 교체합니다.
    context Context 아니요 현지화를 위한 구매자 신호(country, region, postal_code). 판매자는 이를 가격, 재고, 통화를 정하는 데 사용합니다. 생략하면 geo-IP로 대체합니다.
    signals Signals 아니요 승인과 악용 방지를 돕기 위해 플랫폼이 제공하는 환경 데이터. 값은 구매자가 주장한 내용이어서는 안 됩니다(MUST NOT). 플랫폼은 직접 관찰했거나 독립적으로 검증 가능한 제3자 증명에 근거한 신호를 제공합니다. 여러 확장이 공유 네임스페이스에 값을 추가할 때 출처를 보장하고 충돌을 막기 위해, 모든 신호 키는 반드시 역도메인 이름을 사용해야 합니다(MUST).
    attribution Attribution 아니요 플랫폼이 내보내는 추천 및 전환 이벤트 맥락: 캠페인 식별자, 클릭 ID, source/medium 마커 등. 브라우저 기반 흐름에서 플랫폼이 URL 쿼리 매개변수로 전달하는 것과 같은 매개변수입니다.
    buyer Buyer 아니요 개인화된 견적을 위한 구매자 정보(선택 사항).
    currency string 예 ISO 4217 통화 코드. 판매자가 컨텍스트나 geo-IP를 바탕으로 결정합니다.
    totals Totals 예 예상 비용 내역. 배송비·세금을 아직 계산할 수 없으면 일부만 포함될 수 있습니다.
    messages Array[Message] 아니요 검증 메시지, 경고 또는 안내성 알림.
    links Array[Link] 아니요 판매자 링크(선택 사항, 정책, FAQ).
    continue_url string 아니요 장바구니 핸드오프와 세션 복구용 URL. 공유와 사람이 개입하는(human-in-the-loop) 흐름을 지원합니다.
    expires_at string 아니요 장바구니 만료 타임스탬프(RFC 3339). 선택 사항.

    Catalog Lookup¶

    식별자로 상품·변형을 조회합니다. 일괄 조회(lookup_catalog)와 단일 상품 상세 조회(get_product)를 지원합니다.

    Catalog Search¶

    상품 카탈로그 검색 기능.

    Checkout¶

    이름 타입 필수 설명
    ucp any 예 체크아웃 응답용 UCP 메타데이터.
    id string 예 체크아웃 세션의 고유 식별자.
    line_items Array[Line Item] 예 체크아웃 중인 라인 아이템 목록.
    buyer Buyer 아니요 구매자 정보.
    context Context 아니요 관련성 판단과 현지화를 위한 잠정적 구매자 신호로, 권위 있는 데이터가 아닙니다. 검증된 입력(예: 배송 주소)이 없으면 비즈니스는 이 값을 사용해야 하며(SHOULD), 더 신뢰도 높은 신호(인증된 계정, 위험 탐지)나 규제 제약(수출 통제)과 맞지 않으면 무시하거나 우선순위를 낮출 수 있습니다(MAY). 자격 판단과 정책 적용은 반드시 체크아웃 시점에 구속력 있는 거래 데이터로 수행해야 합니다(MUST). 컨텍스트는 개인을 식별할 수 없어야 하며(SHOULD), 단계적으로 공개할 수 있습니다. 초기에는 대략적인 신호를, 세션이 진행되면서 더 세밀한 정보를 제공합니다. 더 세밀한 데이터(배송 주소, 청구 주소)가 컨텍스트보다 우선합니다.
    signals Signals 아니요 승인과 악용 방지를 돕기 위해 플랫폼이 제공하는 환경 데이터. 값은 구매자가 주장한 내용이어서는 안 됩니다(MUST NOT). 플랫폼은 직접 관찰했거나 독립적으로 검증 가능한 제3자 증명에 근거한 신호를 제공합니다. 여러 확장이 공유 네임스페이스에 값을 추가할 때 출처를 보장하고 충돌을 막기 위해, 모든 신호 키는 반드시 역도메인 이름을 사용해야 합니다(MUST).
    attribution Attribution 아니요 플랫폼이 내보내는 추천 및 전환 이벤트 맥락: 캠페인 식별자, 클릭 ID, source/medium 마커 등. 브라우저 기반 흐름에서 플랫폼이 URL 쿼리 매개변수로 전달하는 것과 같은 매개변수입니다.
    status string 예 현재 단계와 필요한 조치를 나타내는 체크아웃 상태. 상태 전이에 대한 자세한 내용은 체크아웃 상태 수명 주기 문서를 참고하세요.
    허용 값: incomplete, requires_escalation, ready_for_complete, complete_in_progress, completed, canceled
    currency string 예 판매자가 판단한 시장을 반영하는 ISO 4217 통화 코드. 주소, 컨텍스트, geo IP로 결정합니다. 구매자는 신호를 제공하고 통화는 판매자가 결정합니다.
    totals Totals 예 장바구니의 각종 합계.
    messages Array[Message] 아니요 체크아웃 세션 상태에 대한 오류·정보 메시지 목록.
    links Array[Link] 예 플랫폼이 표시할 링크(개인정보처리방침, 이용약관). 법적 준수를 위해 필수입니다.
    expires_at string 아니요 RFC 3339 만료 타임스탬프입니다. 보내지 않으면 기본 TTL은 생성 시점부터 6시간입니다.
    continue_url string 아니요 체크아웃 핸드오프와 세션 복구용 URL. status가 requires_escalation이면 반드시 제공해야 합니다(MUST). 형식과 가용성 요구 사항은 명세를 참고하세요.
    payment Payment 아니요 핸들러를 포함한 결제 구성.
    order Order Confirmation 아니요 이 체크아웃 세션으로 생성된 주문의 세부 정보.

    Order¶

    이름 타입 필수 설명
    ucp any 예 주문 응답용 UCP 메타데이터. 구매 후에는 결제 핸들러가 필요 없습니다.
    id string 예 고유 주문 식별자.
    label string 아니요 주문을 식별하기 위한 사람이 읽을 수 있는 라벨. 반드시 비즈니스만 제공해야 합니다(MUST).
    checkout_id string 예 정산 대사를 위한 연관 체크아웃 ID.
    permalink_url string 예 판매자 사이트에서 주문에 접근하는 퍼머링크.
    line_items Array[Order Line Item] 예 구매한 항목을 나타내는 라인 아이템. 주문 후 수정이나 교환으로 바뀔 수 있습니다.
    fulfillment object 예 풀필먼트 데이터: 구매자 예상 정보와 실제로 일어난 일.
    adjustments Array[Adjustment] 아니요 풀필먼트와 독립적으로 존재하는 주문 후 이벤트(환불, 반품, 크레딧, 분쟁, 취소 등).
    currency string 예 ISO 4217 통화 코드. 반드시 원래 체크아웃 세션의 통화와 일치해야 합니다(MUST).
    totals Totals 예 주문의 각종 합계.
    messages Array[Message] 아니요 비즈니스 결과 메시지(오류, 경고, 정보). 비즈니스가 플랫폼에 상태나 문제를 전달해야 할 때 포함됩니다.
    attribution Attribution 아니요 원래 체크아웃과 연결된 어트리뷰션의 스냅샷입니다. 주문에서는 읽기 전용입니다.

    Payment¶

    이름 타입 필수 설명
    instruments Array[Payment Instrument Selected Payment Instrument] 아니요 이 결제에 사용할 수 있는 결제 수단. 각 결제 수단은 handler_id 필드로 특정 핸들러와 연결됩니다. 핸들러는 기본 payment_instrument 스키마를 확장해 핸들러별 필드를 추가할 수 있습니다.

    타입 스키마¶

    Payment Account Info¶

    이름 타입 필수 설명
    payment_account_reference string 아니요 EMVCo PAR. 결제 카드를 특정 계좌에 연결하는 고유 식별자로, 여러 토큰(Apple Pay, 실물 카드 등)에 걸쳐 추적할 수 있게 합니다.

    Adjustment¶

    이름 타입 필수 설명
    id string 예 조정 이벤트 식별자.
    type string 예 조정 유형(개방형 문자열). 일반적으로 refund, return, credit, price_adjustment, dispute, cancellation처럼 금전과 관련된 값입니다. 판매자 비즈니스에 맞는 어떤 값이든 사용할 수 있습니다.
    occurred_at string 예 이 조정이 발생한 시점의 RFC 3339 타임스탬프.
    status string 예 조정 상태.
    허용 값: pending, completed, failed
    line_items Array[object] 아니요 영향을 받는 라인 아이템과 수량(선택 사항).
    totals Array[Total] 아니요 조정 합계 내역. 부호가 있는 값으로, 구매자에게 돌려주는 금액(환불, 크레딧)은 음수, 추가 청구(교환)는 양수입니다.

    payment object 아니요 핸들러를 포함한 결제 구성.
    order object 아니요 이 체크아웃 세션으로 생성된 주문의 세부 정보.

    Allocation¶

    할인 금액이 특정 대상에 어떻게 배분되었는지 보여 주는 내역.

    이름 타입 필수 설명
    path string 예 할당 대상을 가리키는 JSONPath(예: '$.line_items[0]', '$.totals.shipping').
    amount integer 예 이 대상에 배분된 금액(ISO 4217 최소 통화 단위).

    Applied Discount¶

    성공적으로 적용된 할인.

    이름 타입 필수 설명
    code string 아니요 할인 코드. 자동 할인에서는 생략됩니다.
    title string 예 사람이 읽을 수 있는 할인 이름(예: 'Summer Sale 20% Off').
    amount integer 예 ISO 4217 최소 단위로 표시한 총 할인 금액.
    automatic boolean 아니요 판매자 규칙에 따라 자동으로 적용되면(코드 불필요) true.
    method string 아니요 배분 방식. 'each' = 항목마다 독립적으로 적용. 'across' = 금액에 비례해 나눔.
    허용 값: each, across
    priority integer 아니요 할인 계산 시 적용 순서. 숫자가 낮을수록 먼저 적용됩니다(1 = 첫 번째).
    provisional boolean 아니요 이 할인에 추가 검증이 필요하면 true.
    eligibility string 아니요 비즈니스가 이 할인에 대해 인정한 적격성 주장. context.eligibility의 값 중 하나에 해당합니다. 코드 기반 할인과 적격성과 무관한 자동 할인에서는 생략됩니다.
    allocations Array[object] 아니요 이 할인이 배분된 위치 내역. 배분 금액의 합은 총액과 같습니다.

    expires_at string 아니요 RFC 3339 만료 타임스탬프입니다. 보내지 않으면 기본 TTL은 생성 시점부터 6시간입니다.
    continue_url string 아니요 체크아웃 핸드오프와 세션 복구용 URL. status가 requires_escalation이면 반드시 제공해야 합니다(MUST). 형식과 가용성 요구 사항은 명세를 참고하세요.
    payment object 아니요 핸들러를 포함한 결제 구성.
    order object 아니요 이 체크아웃 세션으로 생성된 주문의 세부 정보.
    fulfillment object 아니요 풀필먼트 세부 정보.

    기능(Capability)¶

    이 객체는 기능 또는 확장 하나를 설명합니다. 디스커버리 프로필과 응답의 capabilities 배열에 나타나며, 맥락마다 필수 필드가 조금씩 다릅니다.

    기능(디스커버리)¶

    디스커버리 프로필에 나타나는 형태입니다.

    플랫폼 수준 디스커버리를 위한 전체 기능 선언. 에이전트가 가져갈 spec/schema URL을 포함합니다.

    이름 타입 필수 설명
    version string 예 YYYY-MM-DD 형식의 엔티티 버전.
    spec string 예 사람이 읽을 수 있는 명세 문서의 URL.
    schema string 예 이 엔터티의 구조와 페이로드를 정의하는 JSON Schema의 URL.
    id string 아니요 이 엔터티 인스턴스의 고유 식별자. 인스턴스가 여러 개일 때 구분하는 데 사용합니다.
    config object 아니요 엔티티별 구성. 구조는 각 엔티티의 스키마가 정의합니다.
    extends OneOf[] 아니요 이 항목이 확장하는 상위 기능. 확장에는 있고 루트 기능에는 없습니다. 상위가 여럿인 확장은 배열을 사용합니다.
